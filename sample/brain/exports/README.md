# Exports

Put your export files here: LinkedIn archive .zip, WhatsApp chat exports, calendar .ics or .zip, Apple Contacts .vcf, X archive.

An AI tool can only see the folders you let it see. There are two ways to give it your exports:

- Drag them into this folder. The AI then needs only this brain folder.
- Or leave them in Downloads, and allow the AI to use Downloads when it asks. It can then read and change everything in Downloads for that chat.

The files you put here are never included in the GitHub backup.
