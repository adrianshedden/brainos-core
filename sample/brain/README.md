# My brain

This folder is my second brain. It is plain Markdown, YAML and JSONL files, so any AI can read it.

A second brain is everything the AI remembers about you and your work and life. Facts, history, and how you like things done. The agent is what acts on it, tools are how it acts.

- `CLAUDE.md`, `GEMINI.md` and the top of `AGENTS.md`: level 1, the same words in three places, because each AI opens a different one first. Who this is for, how to start, the rules.
- `AGENTS.md`, below level 1: which folder or skill answers which request, and where every file is.
- `DOMAINS.md`: the folders (domains) this brain has. Each has its own `{DOMAIN}.md` saying what goes in it.
- `memory/`: what has happened: calendar, conversations, decisions, events.
- `skills/`: things an AI can do for me, one folder each, with a `SKILL.md`.
- `tools/`: which AI tools and connectors I use, and how to point each at this folder.
- `automations/`: jobs I have asked an AI app to run on a schedule.
- `scripts/`: small helper programs.
- Personal domains I chose, such as `network/` (people I know and our conversations).

`exports/` is where I put my export files (LinkedIn, WhatsApp, calendar, contacts, X) before importing them. They are never backed up to GitHub. `kit/`, if you have it, is BrainOS itself, which your AI set you up with: leave it as it is.

Start with `CLAUDE.md` (or `AGENTS.md`, or `GEMINI.md`: they open with the same words).
