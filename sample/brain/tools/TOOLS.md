# Tools

This brain does not read itself. Point whichever AI you use at this folder, or give it the files. Nothing here sends anything to an AI by itself: you choose what it sees.

## AI tools

Pick the card for your tool, in `ai-tools/`:

- `claude-desktop.md`: the Claude app's Chat tab (Cowork, the old name, is now part of Chat)
- `claude-ai.md`: Claude in a web browser
- `claude-code.md`: Claude Code
- `chatgpt.md`: ChatGPT (use the desktop app's Codex for your brain)
- `codex.md`: OpenAI Codex
- `gemini.md`: Gemini, in Google's Antigravity app
- `opencode.md`: OpenCode
- `cursor.md`: Cursor
- `orca.md`: Orca
- `other-ai-tools.md`: anything else

Every line on a card names where it comes from and the date it was checked, or says plainly that it was not checked. Tools change. If a card disagrees with the tool's own help page, the help page wins.

Your brain's files stay in your folder. When you ask a question, the parts the AI reads go to the AI company to work out the answer, the same as any chat with it. The kit sends nothing anywhere else.

## Connectors that are on

Connectors are switched on in your AI app (for example Gmail or Google Calendar in the Claude app's settings), never built in this folder. A skill reads a connector only if it is listed here. For the AI: the first time you use a connector that is not listed, add its line here without asking, then tell the person once that you have. For the person: remove a line when you turn the connector off.
