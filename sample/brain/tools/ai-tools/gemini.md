# Gemini (Google Antigravity)

Open this brain folder in Antigravity. It reads `GEMINI.md` and `AGENTS.md` here by itself.

## How to point it at your brain

- Antigravity is Google's desktop app for working on a folder with Gemini; download it from its own site. (Source: https://antigravity.google/download, checked 18 October 2026)
- In the folder you open, it reads an `AGENTS.md` or `GEMINI.md` file as standing instructions, in the top folder and in any sub-folder it works in. (Source: https://antigravity.google/docs/rules, checked 18 October 2026)

## What it can do

- Read and change the files in the folder you opened, and run commands there when you allow it. (Not checked: the rules page describes instruction files only, not file or command permissions.)

## What it cannot do

- Use the Gemini app's connections to your email or calendar from inside this folder. Bring those in as export files instead. (Not checked: Google's pages do not say either way.)
- Work from the Gemini app on the web or a phone: those cannot open a folder on your computer. (Not checked: no Google page says this directly.)
