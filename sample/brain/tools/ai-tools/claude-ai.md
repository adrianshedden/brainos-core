# Claude in a web browser (claude.ai)

Put the brain's files in a Project, then ask your questions inside that Project.

## How to point it at your brain

- Make a Project and upload the brain's files to its knowledge. Projects are on every plan, including Free, which allows up to five. (Source: https://support.claude.com/en/articles/9517075-what-are-projects, checked 1 October 2026)
- Or, if your brain is backed up to your own GitHub (see the BrainOS GitHub guide), connect that repo with Claude's GitHub integration. Private repos work. (Source: https://support.claude.com/en/articles/10167454-use-the-github-integration, checked 1 October 2026)

## What it can do

- Answer from the files you gave it. The GitHub integration brings in file names and contents from one branch. (Source: https://support.claude.com/en/articles/10167454-use-the-github-integration, checked 1 October 2026)
- "Sync now" fetches the latest version of your repo after you have backed up again. (Source: https://support.claude.com/en/articles/10167454-use-the-github-integration, checked 1 October 2026)

## What it cannot do

- Add to your brain. (Not checked: neither help page describes Claude writing back to your files or your repo, so treat it as read-only.)
- See your brain's history. It gets the files only, no commit history. (Source: https://support.claude.com/en/articles/10167454-use-the-github-integration, checked 1 October 2026)
- Hold an unlimited amount. Each file can be up to 30MB, and everything together has to fit in what Claude can hold at once. (Source: https://support.claude.com/en/articles/8241126-upload-files-to-claude, checked 1 October 2026)
- Notice when your folder changes. (Not checked: the upload help page does not say whether uploaded files update, so re-upload or press "Sync now" after you re-import.)
