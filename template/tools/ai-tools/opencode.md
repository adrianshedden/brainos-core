# OpenCode

Start it inside this brain folder and tell it: "Read CLAUDE.md first."

## How to point it at your brain

- It comes as a terminal app, a desktop app or a code-editor extension. (Source: https://opencode.ai/docs, checked 1 October 2026)
- Go to the brain folder and run `opencode` there. (Source: https://opencode.ai/docs, checked 1 October 2026)

## What it can do

- Work with more than 75 AI providers, including models that run on your own computer. (Source: https://opencode.ai/docs/providers, checked 1 October 2026)
- It is open source. (Source: https://opencode.ai/docs, checked 1 October 2026)

## What it cannot do

- Bring its own AI: you connect a provider and pay that provider. (Not checked: the docs say open source but give no price.)
- Edit files. (Not checked: the docs show undo and redo for changes, but we did not find a plain statement that it edits files.)
