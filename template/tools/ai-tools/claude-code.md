# Claude Code

Start it inside this brain folder and tell it: "Read CLAUDE.md first."

## How to point it at your brain

- You start Claude Code in a folder on your own computer. It also runs inside code editors, the Claude desktop app and a web browser. (Source: https://code.claude.com/docs/en/overview, checked 1 October 2026)
- Claude Code on the web works from your brain's GitHub repo instead, so back up first or it will not see your latest changes. (Source: https://code.claude.com/docs/en/claude-code-on-the-web, checked 1 October 2026)

## What it can do

- Read your files, edit them and run commands. (Source: https://code.claude.com/docs/en/overview, checked 1 October 2026)
- Save changes with git, make branches and open pull requests. (Source: https://code.claude.com/docs/en/overview, checked 1 October 2026)
- On the web, copy your GitHub repo and push its work back to it. (Source: https://code.claude.com/docs/en/claude-code-on-the-web, checked 1 October 2026)

## What it cannot do

- Run without an account: it needs a Claude subscription or an Anthropic Console account, and the desktop app version needs a paid plan. (Source: https://code.claude.com/docs/en/overview, checked 1 October 2026)
- Run on the free plan in a terminal. (Not checked: no help page we read says whether the free plan includes it.)
- Run on the web below Pro: the web version needs Pro, Max or Team, or certain Enterprise seats. (Source: https://code.claude.com/docs/en/claude-code-on-the-web, checked 1 October 2026)
- Give you a separate allowance: on Pro and Max it shares one usage allowance with your Claude chats. (Source: https://support.claude.com/en/articles/11145838-use-claude-code-with-your-pro-or-max-plan, checked 1 October 2026)
